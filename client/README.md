# 🏰 Mewar Delights – Rajasthani Food E-Commerce Website

Mewar Delights is a royal-themed Rajasthani food showcase & e-commerce web application inspired by the heritage cuisine of Rajasthan.

## 🌟 Features
- Royal UI inspired by Mewar heritage
- Product listing with Add to Cart
- Persistent cart using localStorage
- Checkout page (auth-ready)
- Responsive design (desktop & mobile)
- React Context API for state management

## 🛠 Tech Stack
**Frontend**
- React JS
- React Router DOM
- Bootstrap (CDN)
- Custom CSS (Royal theme)

**Backend (Planned)**
- Node.js
- Express.js
- MongoDB
- JWT Authentication
